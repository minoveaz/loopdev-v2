# Archivo de documentación

Esta carpeta contiene documentación histórica, deprecada o sustituida. Se conserva por
trazabilidad de decisiones, contratos legacy, issues y handoffs anteriores, pero no debe
usarse como fuente del estado actual ni como guía para crear nuevas rutas o componentes.

## Fuentes vigentes

- Estado frontend CRM y Communications:
  `tracks/active/crm/2026-09-09-loopdev-v2-crm-frontend.md`
- Matriz única de cierre:
  `docs/06-product/crm/CRM_FRONTEND_CLOSURE_MATRIX.md`
- Documentación vigente de producto:
  `docs/06-product/crm` y `docs/06-product/communications`

## Estructura

- `crm/`: alineación, matriz de cierre y handoffs CRM sustituidos.
- `communications/`: UX y handoffs iniciales de Communications Core e Inbox.

Los documentos archivados no se eliminan porque contienen contexto útil para la futura
integración Supabase, pero cualquier contradicción con las fuentes vigentes debe resolverse
a favor del track activo y de la matriz de cierre.
