## Evidence rules

- Every applicable cell links to a visual-design section or artifact.
- State copy, recovery action, focus/announcement behavior and permission
  semantics are explicit.
- Reuse Rivera/shared LoopDev primitives; record any approved extension.
- Styled SVGs use realistic data and link to the baseline inventory and zone
  reuse matrix.
- Conceptual approval and post-implementation runtime comparison are separate
  evidence requirements.
