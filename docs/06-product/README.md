# Product documentation

Product and suite-specific documentation is organized under this directory.
Active product work should be represented by an approved track and keep its
implementation contracts close to the owning suite.

Before reading or using product documentation for delivery, read
[`../03-platform/governance/V2_DOCUMENTATION_SOURCE_OF_TRUTH.md`](../03-platform/governance/V2_DOCUMENTATION_SOURCE_OF_TRUTH.md).
It defines the authority tiers and distinguishes implemented V2 evidence from
approved intent, proposed references, and archive-only history.
