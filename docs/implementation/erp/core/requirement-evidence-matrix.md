## Release blockers

- The required hierarchical category manager and its domain lifecycle are absent.
- Product media has approved conceptual desktop/mobile visuals, but no
  organization-library reuse flow, image normalization/derivative processing,
  or authenticated desktop/mobile validation.
- Purchase-cost authorization and SKU-level behavior are incomplete; current
  access documentation and UI/runtime behavior are not aligned.
- The foundation catalog RLS policy has a documented read-only-delete risk.
  Remote writes also require a verified forward policy migration and the shared
  append-only audit contract.
- No approved module-wide plan or authenticated tenant-scoped runtime journey
  exists; migration/data dry-run and rollback evidence remain outstanding.

## Known deviations

- `/app/erp/products` is implemented using legacy `catalog.*` domain contracts;
  it is not yet the approved canonical Products capability contract.
- The media screen uses a product-specific Supabase adapter and media tables.
  It reuses the shared `FilePicker` and `platform_files` table, but generic
  Platform Files ownership/reusable associations have not been approved as a
  complete shared contract.
- Image tiles have a consistent square display frame, but image files are not
  resized or normalized on upload.
- Shopify, Inhand commerce, native apps, inventory, suppliers and other ERP
  modules are intentionally outside this release.
