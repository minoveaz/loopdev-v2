1. Introduction

Rivera — Multipurpose React Admin Dashboard Template

Version v1.0.0Frontend-onlyReact + Vite

Rivera is a frontend-only multipurpose React admin dashboard template. It ships with multiple dashboards, 20+ apps (Email, Chat, Calendar, Kanban, Tasks, Meetings, Invoices, AI Chatbot, …), eCommerce + POS, NFT, Real Estate, Logistics, Marketing, Academy, Blogs, Subscriptions, Helpdesk and User Management modules — all powered by mock data persisted to localStorage. No backend, no database, no setup wizard.

2. Technology Stack

  • React 18
  • TypeScript
  • Vite 8
  • Tailwind CSS 3
  • shadcn/ui (50+ primitives)
  • Recharts
  • React Router
  • lucide-react icons
  • localStorage-backed mock data layer

3. Requirements

  • Node.js 18+ (Node 20 LTS recommended)
  • Any of: npm, yarn, pnpm, or bun
  • A modern browser (Chrome, Edge, Firefox, Safari)

No .env file is required — Rivera has no API keys or backend.

4. Installation

From the extracted project folder:

npm install
# or: yarn
# or: pnpm install
# or: bun install

5. Development

npm run dev

Starts the Vite dev server with HMR on http://localhost:8080 (configurable in vite.config.ts).

6. Production Build

npm run build

Outputs a fully static bundle to ./dist/.

7. Preview Build

npm run preview

Serves the built ./dist/ locally so you can sanity-check the production bundle before deploying.

9. Theme Customizer

Rivera ships a runtime Theme Customizer drawer (top bar) that controls:

  • Theme mode — light / dark / system
  • Primary color — choose from 6 brand presets
  • Density — comfortable / compact
  • Sidebar style — default / bordered / floating
  • Sidebar mode — expanded / collapsed
  • Navbar style — default / sticky / transparent
  • Radius — corner radius scale
  • Content width — fluid / boxed
  • Chart style — line curve / bar variant
  • Direction — LTR / RTL
  • Reset to default — one-click restore

All choices persist to localStorage under the key rivera-theme-config and sync across tabs.

10. Mock Data

  • No backend is included. Rivera is a pure frontend template.
  • All entities are mocked and persisted to localStorage.
  • Seeds live in src/data/ (e.g. mockUsers.ts, mockOrders.ts, mockProducts.ts, …).
  • Generic helpers in src/lib/localStore.ts / src/lib/storage.ts read and write each store.

Reset localStorage

// In the browser DevTools console:
localStorage.clear();
location.reload();

Or use DevTools → Application → Storage → Clear site data.

11. Routing

  • Rivera uses React Router.
  • Every page is lazy-loaded with React.lazy(() => import(...)) and rendered inside a <Suspense> boundary with a skeleton fallback.

Add a new route

  1. Create the page under src/pages/....
  2. In src/routes/AppRoutes.tsx add: 
    const MyPage = lazy(() => import("@/pages/MyPage"));
// inside the AppShell block:
<Route path="/my-path" element={<MyPage />} />

Add a sidebar menu item

Edit src/app/navigation.ts and add an entry with the matching path, label and lucide icon. The sidebar reads from this file, so menus stay in sync with routes.

12. Components

  • shadcn/ui — 50+ accessible primitives in src/components/ui/ (Button, Dialog, Table, Form, …).
  • Rivera reusable components in src/components/common/:
    • DataTable — sortable, filterable table with pagination.
    • StatCard — metric card with trend indicator.
    • ChartCard — chart container with header + legend.
    • PageHeader, PageContainer, EmptyState, LoadingSkeleton, and more.
  • Theme Customizer — src/components/theme/ThemeCustomizer.tsx.

13. Build & Deployment

  1. Run npm run build to generate ./dist/.
  2. Upload only the contents of dist/ to your static host (Netlify, Vercel, Cloudflare Pages, GitHub Pages, S3 + CloudFront, nginx, Apache, …). Add an SPA rewrite (/* → /index.html).
  3. Do not include the dist/ folder in the ThemeForest source package. Reviewers and buyers will run npm install and npm run build themselves.

14. Customization

Change the logo / brand name

Edit src/components/layout/Logo.tsx to swap the SVG/text. The product name string also appears in index.html and public/site.webmanifest.

Change the primary color

Edit the brand palettes in src/config/themeConfig.ts and the HSL CSS variables in src/index.css. Never hardcode colors in components — always use semantic Tailwind tokens (bg-primary, text-foreground, …).

Update mock data

Edit the relevant file in src/data/ (e.g. mockUsers.ts). After editing, clear localStorage so fresh seeds are written.

Edit sidebar navigation

Edit src/app/navigation.ts. Each entry has a label, path, optional icon and optional children.

Edit dashboard cards / charts

Dashboards live in src/pages/dashboards/ (Analytics, CRM, Ecommerce, Restaurant). Swap data sources, change chart types (Recharts), or rearrange StatCard / ChartCard components.

16. Support

When requesting support, please include:

  • Your ThemeForest purchase code.
  • Rivera version (see CHANGELOG.md).
  • Node.js version (node -v) and package manager.
  • Operating system and browser (with version).
  • Exact steps to reproduce the issue.
  • Screenshots or a short screen recording, if visual.
  • Full console output and any network errors.

Tip: try clearing localStorage first — many UI issues vanish after re-seeding the mock data.
