# Archived Platform Documentation

This directory contains discarded or superseded Platform proposals retained
for traceability only. Nothing in this directory is an active LoopDev v2
contract, runtime capability, component registry or implementation dependency.

The archived `SAAS_*` documents describe an earlier composition and visual
standardization direction. `SAAS_VIEW_SPECIFICATION_TEMPLATE.md`,
`PLATFORM_SANDBOX_RUNTIME.md`, `PLATFORM_SHELL_MODE_INVENTORY.md` and
`SHELL_SHOWCASE_CONTRACT.md` are also proposals, exploratory inventories or
showcase material without verified V2 runtime consumers. The archived
`CREATIVE_EDITOR_DESIGN_HANDOFF.md`, `DOMAIN_VALIDATION_ROUTING_HANDOFF.md`
and `PLATFORM_SHELL_COMPATIBILITY_MATRIX.md` are historical handoffs or
phase-gate artifacts, not active V2 contracts. None of these documents was
implemented as a verified V2 runtime and they must not be used to design new
module behavior.

The moved `PLATFORM_COMPONENT_INVENTORY.md` and
`PLATFORM_SHELL_ZONE_CONTRACT.md` are legacy documents retained only for
historical traceability. They are not current V2 sources.

Use these current sources instead:

- `../governance/V2_DOCUMENTATION_SOURCE_OF_TRUTH.md`
- `../frontend/PLATFORM_V2_UI_REFERENCE.md`
- `../frontend/PLATFORM_V2_SHELL_REFERENCE.md`
- `../../06-product/crm/CRM_UI_COMPONENT_PROTOCOL.md`
- module-specific approved design documents under
  `../../implementation/<suite>/<module>/`
