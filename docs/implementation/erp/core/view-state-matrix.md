# ERP Core — Matriz de vistas y estados

Esta matriz es fuente normativa de cobertura visual. Los SVG prueban la
composición aprobada conceptualmente, no la implementación ni la paridad
funcional. El scope funcional de este release es Products/categorías en web
desktop/mobile, incluyendo coste unitario de compra de referencia no contable y
atributos físicos estructurados. El Overview solo documenta la superficie actual. En modo
`supabase`, offline significa no disponible: no se muestra cache remoto ni se
encolan mutaciones. `local_demo` es un modo aislado y explícito.

## Reglas de evidencia

- Cada celda representa diseño objetivo; la presencia de un estado en esta
  matriz no afirma que la ruta actual lo implemente.
- La fuente visual se revisa conceptualmente antes de cualquier trabajo
  especializado. Comparación visual de runtime queda `NOT_RUN` hasta que haya
  implementación.
- Breakpoints, teclado, foco, safe areas, contraste y operación completa en
  mobile web siguen sujetos a evidencia; no se infieren de un SVG.
- Offline remoto es `unavailable`, no cache ni cola. `local_demo` es separado,
  explícito y no se mezcla con organizaciones Supabase.
