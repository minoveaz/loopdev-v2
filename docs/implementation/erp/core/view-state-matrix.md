## Reglas de evidencia

- Cada celda representa diseño objetivo; la presencia de un estado en esta
  matriz no afirma que la ruta actual lo implemente.
- La fuente visual se revisa conceptualmente antes de cualquier trabajo
  especializado. Comparación visual de runtime queda `NOT_RUN` hasta que haya
  implementación.
- Breakpoints, teclado, foco, safe areas, contraste y operación completa en
  mobile web siguen sujetos a evidencia; no se infieren de un SVG.
- Estados de sync, conflicto remoto y caché son propuestas de diseño; requieren
  contratos de dominio/API/sync aprobados y no se presentan como runtime.
