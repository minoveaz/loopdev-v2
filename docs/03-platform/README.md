# LoopDev v2 platform documentation

Active platform documentation is organized by responsibility. These documents
are current references only when their status and repository evidence support
that claim; archived material remains historical and is not an implementation
source.

- [`frontend/`](frontend/) — implemented web UI, shell, navigation, and shared
  frontend behavior.
- [`backend/`](backend/) — API, persistence, storage, tenancy, and backend
  security contracts.
- [`mobile/`](mobile/) — native iOS/Android design reference; native apps are
  not claimed unless source and release evidence exists.
- [`governance/`](governance/) — source-of-truth, architecture, delivery,
  workflow, readiness, and traceability contracts.
- [`archive/`](archive/) — historical documents retained unchanged for
  traceability; do not use as current implementation authority.

Start with [`governance/V2_DOCUMENTATION_SOURCE_OF_TRUTH.md`](governance/V2_DOCUMENTATION_SOURCE_OF_TRUTH.md)
for evidence and authority rules.
